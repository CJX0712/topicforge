# Model Card · TopicFuse

> 依据 [Mitchell et al. 2019] 模型卡规范 · 作者：晨星

## 模型细节

- **名称**：TopicFuse（TopicForge 旗舰）
- **类型**：无监督主题建模（概率生成模型推断）
- **方法**：多链变分贝叶斯 LDA 集成 + Hungarian 共识对齐 + VB 精炼
- **实现**：纯 Python / 纯 NumPy，自实现 digamma 与 Hungarian 算法，零 scipy 运行时依赖
- **版本**：0.1.0（2026-10-07）

## 预期用途

- 从文档集合中发现潜在主题结构（topic discovery）。
- 文档主题聚类与表示。
- 作为主题建模基线研究的强推断器。

## 训练数据

- **合成数据**：标准 LDA 生成模型（Blei et al. 2003）合成语料。
  每个主题取一小撮支撑词 + Gamma 质量，保证主题可区分、可恢复。
- 默认规模：K=6 主题、词表 V=500、N=200 文档、平均长度 50。
- **真实数据**：系统可接入 `Corpus(docs=[...], vocab_size=V)` 真实语料（此时无真实标签，
  recovery / clustering 指标不可用，仅 perplexity 有意义）。

## 评估指标与结果

3 数据集（seed=101/202/303）· K=6 · V=500 · N=200：

| 模型          | recovery     | cluster     | perplexity |
|---------------|--------------|-------------|------------|
| **topicfuse** | **0.9237±0.046** | **0.7900±0.059** | **62.027** |
| lda           | 0.8235±0.039 | 0.7417±0.019 | 77.128     |
| nmf           | 0.9906±0.001 | 0.9049±0.041 | 49.158     |
| tfidf_kmeans  | 0.8206±0.009 | 0.7667±0.027 | —          |
| random        | 0.0993±0.038 | 0.2350±0.012 | —          |

- **头条**：topicfuse − lda 主题恢复度 Δ = **+0.1002**（门槛 0.02，PASS）。
- 指标口径：recovery / cluster 越大越好；perplexity 越低越好。
- NMF 在合成数据上 recovery 最高，但其为非负分解、非概率生成模型，与 LDA 族不可直接比较语义；
  TopicFuse 的价值在于**在概率生成模型族内**稳定优于单链 VB-LDA 并降低方差。

## 确定性

同 seed 两次运行，16 项核心指标逐位一致（`max|Δ| = 0`）。

## 局限性

- 主题数 K 需预先指定（未内置模型选择）。
- 合成基准中主题高度可区分；真实语料主题可能重叠、稀疏，recovery 口径需真实标签，通常不可用。
- VB-LDA 对超参数 `alpha / eta` 敏感，默认经合成域调优，真实数据建议网格搜索。
- 大规模语料（百万级 token）为纯 NumPy 实现，未做稀疏化加速。

## 伦理与环境考量

- 纯 CPU 推理，无 GPU / 无大模型权重下载，碳排放极低。
- 主题为无监督发现，可能反射训练语料中的偏见；部署于敏感领域需人工审查主题语义。
